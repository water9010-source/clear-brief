# 交辦單寫法 Clear Brief — Claude Skill

AI 把工作交給另一個 AI 或新開的對話時，最常出事的是「對方理解錯了」。這個 Skill 給 AI 四條寫法規則、一份可直接套用的範本、正反範例和常見誤會清單，讓接手的一方照字面就能做對。

## 怎麼用
- 寫交辦單時照四條規則：詞要定義、指令寫動作不寫工具名、依據附原文與位置、列出必讀檔與需要的能力。
- 套用範本，接手方開工第一句回一行收到確認。
- 附正反範例與常見誤會清單，寫完自己對一次。

## 限制
- 還沒有實際使用紀錄。
- Skill 內容是繁體中文。
- 不保證一定有效；AI 不一定每次都照做。
